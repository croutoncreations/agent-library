# Changelog

## Unreleased

- **Optional review per document** ([docs/review-gating.md](docs/review-gating.md)). A workspace admin can require review (or just mark reviewed versions) per document, with a project default. Edits by OAuth apps, API keys and agent tokens to a document that requires review become proposals; people are never gated, and App Connect files never are. People with write access to the project, and agent connections an admin allowed (Can review), approve, approve with edits or reject. Proposals are private (never in search, the changes feed, agent listings or offline copies); their text lives in R2 like version text (migration `0033_proposal_text_keys.sql`) and the bytes of closed proposals are removed after 30 days. Backups with review data are `agent-library-backup/4`; import and restore read `/1` to `/4`.
- **Search index is contentless.** Migration `0031_search_contentless.sql` replaces the full-text table, which stored a copy of every document's title and text (up to 1 MiB each), with a contentless FTS5 table: D1 keeps only the inverted index, and every word stays searchable (about 38% of the previous index size for 10 KB documents; `scripts/search/measure-index-size.mjs`). Text is read from R2 for excerpts after the page of results is chosen. All index writes now go through `packages/core/src/search/indexing.js` in the same batch as the change, replacing the database triggers, and the cron rebuilds the index from stored text (15 documents per run) instead of `scripts/search/backfill.mjs`, which is removed. The migration is marked `owner-approved-destructive` (it drops the derived index), so it is applied in a manual window, and search is unavailable on an existing installation until the rebuild finishes. Worker rollback past it is not supported.
- **The installed app opens instantly, offline or on a slow connection** ([docs/offline.md](docs/offline.md)). The service worker now serves the app shell (page, script, styles, manifest, icons; cache `al-shell-v3`) cache-first, for `/`, `/p/…` and project addresses `/<workspace>/<project>`, and never sign-in pages, invitations, installation routes, library data or the user-content and MCP hosts. With saved copies, boot waits at most 3 seconds for sign-in, then opens them read-only while signing in continues; only a 401 (or an Access redirect on a self-hosted installation) leads to a sign-in screen, an unreachable library shows the offline page. Requests give up after 15 seconds and **Try again** signs in again in place. A deploy reaches an installed app on the launch after the one that downloaded it (`GET /shell-version`, `X-Shell-Version`). No migration, no new vars.
- Loading lists (Home, Projects, a project's documents and trash) no longer show a clipped "Lc" sliver above the placeholders. The hidden "Loading…" text for screen readers was its own list row and lost to the list row styles. The placeholders now look like real rows (icon tile, title and details) with a staggered pulse, which stops when reduced motion is on.
- Sign out now ends the session on the server even when the page's request token is out of date (a session renewal was in flight, or another tab had renewed the session). Before, on installations behind Cloudflare Access, the app could show "Signed out" while the session stayed valid on the server until it expired; using it still needed a valid Cloudflare Access sign-in.
- Stored data relies on Cloudflare's at-rest encryption for D1 and R2; Agent Library adds no encryption of its own. The unused content-encryption code (workspace data keys, the `keyProvider` adapter, encrypted file objects, publication fences) and the blind-search token tables are gone, search stays plaintext full-text, and a Worker no longer refuses to start when `CONTENT_MASTER_KEY_*` or `CONTENT_ENCRYPTION_REQUIRED` is set. The deploy preflight's forbidden names are now only `AC_TEST_HOOKS` and `V1_TEST_ENDPOINTS`.
- The migration history was rewritten: the key, fence, encrypted-blob and blind-search migrations are removed, `0017_review_gating.sql` is added and the later migrations are renumbered (`0018_workspaces.sql` to `0030_workspace_purge.sql`). A database that applied the earlier numbering must be reset before this release. Import and restore now accept file keys up to R2's 1,024-byte limit (before: 1,015).
- **App Connect is now one simple "app data folder" API.** An app calls `GET /v1/app`, `GET /v1/app/files`, and `GET`, `PUT` and `DELETE /v1/app/files/{path}` (text files up to 1 MiB, `If-Match` / `If-None-Match`, an `Idempotency-Key` on every write; see docs/app-connect.md). Removed with no replacement: `/v1/publisher/*`, snapshots, staged generations, upload slots and drain budgets, the per-app lifetime counters, and case-insensitive path conflicts. Paths are now lowercase `[a-z0-9._-]` with an extension only on the last segment. To update several files consistently, write the data files first and `index.json` last with `If-Match`. Apps that used the old routes must be updated; existing snapshot and generation tables are left in place unused. Files an app wrote are marked with `app_path` in artifact metadata, and `list_artifacts` (and `GET /v1/projects/{id}/files`) take an `app_path` filter. Migrations `0030_app_files_counters.sql` and `0031_app_files_path_index.sql` (never released) are gone; `0032_workspace_purge.sql` is now `0030_workspace_purge.sql`, so a database that applied the unreleased numbering must be reset.
- **Backups include App Connect files.** The `backup_unsupported` refusal is gone. A project export marks an app's files with `app: { name, path }` (backup schema 3). Restore and import make them ordinary, editable files (title = path, tag `app:<name>`).

## 0.1.0 (2026-10-28)

First open-source release.

- Projects, folders and artifacts (Markdown, HTML, JSON, CSV, images, PDF, video) with immutable version history (who, via which client, why), diff and restore.
- Remote MCP server with OAuth (ChatGPT, Claude, Cursor and local clients), per-connection project scopes and revocation; scoped API keys for the `/v1` HTTP API.
- App Connect: owner-registered apps that store and update only their own files in a chosen project and folder. Apps can suggest a destination (`agentlib_project`, `agentlib_folder`), and owners can set a default per app (migration `0012`).
- Revision-pinned chunked text reads for long documents: `read_artifact` `max_bytes`/`cursor` on both MCP endpoints, `GET /v1/projects/:p/files/:f/text` and the browser API ([docs/chunked-reads.md](docs/chunked-reads.md)).
- Installable browser UI (desktop and phone) behind Cloudflare Access.
- Offline self-host generator (`npm run setup:self-host`) and an optional GitHub deploy pipeline with read-only preflight, additive-only migrations, smoke checks and receipts.
- All installation-specific values come from configuration. New `OAUTH_EXTRA_REDIRECT_URIS` var for trusting extra exact OAuth callbacks (for example your own MCP gateway).
- App Connect generation formats are now `agentlib.generation.index/1` and `agentlib.generation.part/1`. The earlier format names are still accepted.
- Files for MCP connections: agents connected through OAuth can list files (images, PDFs, video) alongside documents, read them (images inline, any file through a 10-minute single-version download link that honours revocation) and, with Edit, upload new files and new versions (`upload_begin` → PUT to a single-upload link → `upload_finish`, with expected revision, idempotency keys and a required change note shown in History). The consent page now says files are included. Connections approved before this keep documents only until reconnected. Needs migration `0013`. Hosted clients that can't make HTTP requests can use `upload_file` (base64, up to 2 MiB). Rate-limited MCP calls now return a readable `rate_limited` tool error with the limit and seconds to wait.
- Browser lists show a file's actual type (PNG image, MP4 video, PDF…) instead of "File", with small thumbnails for images and videos on Home, project lists, search and offline copies. Home adds a Type filter and a Sort by type option, saved with the other Home preferences.
- MIT license, third-party notices and reproducible embedded-editor provenance.
